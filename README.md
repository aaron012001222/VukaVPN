# VukaVPN

> 干净真实的静态住宅 IP · 全球合规接入

VukaVPN is a multi-platform VPN client built on Xray + sing-box, designed for professional users — cross-border e-commerce, TikTok/social media operators, advertising operations.

This is a customized fork of [hiddify-app](https://github.com/hiddify/hiddify-app) (MIT license) with our branding and configuration.
